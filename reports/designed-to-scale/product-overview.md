# Product Overview

**Status:** READY WITH ASSUMPTIONS

## Product purpose

The website is an interactive system-design course named "System Design", authored by Dilum Sanjaya. [REPORT.md](REPORT.md) and `index.html` describe it as a free, bilingual-by-design course with animated diagrams and step-by-step explanations.

The educational subject includes:
- Foundations
- Scaling
- Data and storage
- Communication
- Reliability
- Architecture
- Security
- Shipping
- Whole-system design

## Audience

The observed level labels indicate beginner, intermediate, and advanced learners. `q9.out.json` provides lesson duration, level, and step counts. Exact audience personas and target-market assumptions are not established in the evidence.

## Core experience

1. A learner opens the application and enters a lesson step.
2. The lesson stage shows an animated SVG.
3. A guide panel explains the current step.
4. Timeline controls and Next/Back navigate lesson steps.
5. A recap marks the lesson complete.
6. The app advances to or allows selection of another lesson.
7. Search retrieves lessons, steps, and concepts.
8. Theme and language preferences persist locally.

## Application scope

Confirmed scope includes:
- 9 modules
- 40 lessons
- 445 reported lesson steps
- Hash-based deep links
- Search
- Lesson progress
- Theme and language preferences
- Responsive desktop/tablet/mobile layout

Unconfirmed scope includes:
- Accounts
- Remote synchronization
- Analytics
- PWA installation/offline mode
- TTS playback
- Any backend APIs
